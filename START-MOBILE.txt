EAGLE RELAY ON ANDROID

1. Install Termux from a trusted/current source.
2. Copy this folder to your phone.
3. Open Termux and cd into this folder.
4. Run: bash termux-install.sh
5. The relay listens on port 8080.

LOCAL TEST:
ws://PHONE-LAN-IP:8080

IMPORTANT:
This local address is ws://, not encrypted WSS. Do not expose port 8080 directly to the public Internet.

REAL INTERNET WSS:
Use a TLS tunnel/reverse proxy in front of 127.0.0.1:8080. The tunnel provider supplies the public wss:// URL; put that URL into your Sender and Receiver HTML. Use the provider's official Android/Termux instructions because commands vary.

The relay provides ordinary real network messaging over the phone's Internet connection. It does not create a quantum channel, control carrier tower frequencies, or transmit information through time.
